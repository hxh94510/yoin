# 余音 YOIN

日系潮流聊天角色图鉴，基于「老田的嫡系们」的既有档案和聊天记录制作。

线上地址：<https://hxh94510.github.io/yoin/>

## 查看

直接用浏览器打开 `index.html` 即可使用全部核心功能，无需安装依赖、无需联网。

也可以在本目录运行 `node serve.cjs`，打开 `http://127.0.0.1:4173`。端口可通过 `YOIN_PORT` 环境变量修改；服务仅绑定本机。

## 功能

- 首页：原型角色、精选对白、测试入口。
- 首页精选区：每次进入 / 刷新从 11 位角色中随机抽取 4 位，避免连续原样重复。
- 角色图鉴：11 位角色，支持姓名、外号、标签搜索和高倾向筛选。
- 角色档案：完整性格描述、六维雷达、Tag、话题频次、经典原话及上下文、主羁绊。
- 羁绊网络：11 个可点选节点、55 对统计，支持发言转接 / 共同会话排序，5 个主羁绊与 5 个主题组合。
- 原声档案：23 条已核对发送人的引文，支持搜索与角色筛选。
- 测试实验室：首个 10 题情境自测，可返回改选、自动保存、生成六维结果和前三名、下载 SVG 结果卡。
- 自适应手机 / 平板 / 桌面，键盘操作，尊重系统减少动效设置。
- 循环 BGM「軽快なリズム」、动态唱片按键、独立音乐 / 音效开关及音量设置。
- Cuelume 的轻量交互音效覆盖悬停、选择、翻页、展开、结果和操作成功。

## 声音控制

首次打开默认尝试自动播放 BGM；如果浏览器禁止有声自动播放，会显示“轻触页面，开启音乐”，首次点击 / 轻触页面或按 Enter、空格时自动接续播放。不会绕过浏览器的音频权限。右下角唱片按键开启 / 关闭 BGM；音乐开关、音量与音效偏好保存在当前浏览器。手动关闭后，下次打开仍保持关闭。站内导航和切换后台标签页都会保留同一个播放位置；若浏览器或系统在后台暂停媒体，回到页面时会自动续播。

音乐默认音量 20%，交互音效 25%；音频设置中可独立关闭音效。音乐循环播放，切到后台标签页时继续播放；自动播放受限时等待交互，文件加载失败时按键显示重试状态，均不影响正常浏览和测试。

音效使用 [Cuelume 0.2.2](https://github.com/danielwh2/cuelume)，保留 MIT 许可证。模块已打包为本地 IIFE，直接打开 HTML 也可以使用，不依赖 CDN。音乐为用户提供的文件直接复制。

| 交互 | 音效 |
|---|---|
| 鼠标悬停导航 / 角色卡 | tick，库内 150ms 节流，触摸不触发 |
| 改选答案 / 筛选 / 羁绊分页 | toggle；重复选择不响 |
| 上一题 / 下一题 / 普通导航 | page |
| 进入角色 / 展开原话 | bloom；收起为 droplet |
| 开始测试 / 生成结果 | pulse / ready |
| 成功复制 / 生成下载卡 | success |
| 可恢复失败 | error |

系统减少动效时唱片和音柱静止；播放状态仍以文字显示。滑块拖动、打字、滚动与不可用按钮不连续发声。

## 数据与评分

六维顺序：追问、拆解、共鸣、玩梗、行动、精炼。原型数值为基于既有档案的人工设计参数，与发言条数等统计指标分开；不代表标准化心理量表。

网页「数据与设计说明」列明各维解释、10 分钟间隔会话切分、20 分钟主题分段、词簇统计限制，以及评分算法。八卦线索移除了单独的“喜欢”；统计仍是关键词候选，需结合上下文。

每题选项有一个六维向量，题目等权。每维以“各题四个选项等概率被选”的合成参照计算总分均值和标准差，将选择相对该参照的偏移映射到 11 个原型在该维的均值与标准差，最后截断至 0–100。这只是让题目参数与原型参数在同一尺度上比较，不是人群常模。

公式：`分数 = clamp(原型均值 + (选项总分 − 合成均值) / 合成标准差 × 原型标准差, 0, 100)`。按与角色原型的六维均方根距离排序；相似度为 `100 − 距离`，并非概率。模型定义与版本保存在 `tests.js`。

没有分析埋点、远程字体、外部图片、API 或服务端存储。测试进度与结果仅保存在当前浏览器；禁用本地存储时仍可完成当前页面中的测试。

## 扩展测试

1. 在 `tests.js` 的 `window.YOIN_TESTS` 数组中增加配置，提供唯一 `id`、`version`、标题、描述、时长、`status: 'ready'` 与 `questions`。
2. 沿用六维顺序。每个问题包含 `title`、`tag`、`time`、`messages`（说话人/文本数组）、`prompt` 和 `options`。
3. 每个选项包含 `text` 与六个 0–100 的 `vector` 值。当前界面适配四个选项；所有问题应覆盖各个维度的差异。
4. 页面自动生成测试入口和对应路由；题目改变时提升 `version`，旧进度将自动失效。
5. 新测试如采用不同维度或不同结果体系，应单独实现评分与结果展示，不能直接复用当前角色匹配算法。

未来测试卡片目前是编辑计划，不可点击；首个测试已完整实现。所有情境题为新创作，网页原文引用另有来源标识。

## 文件

- `index.html`：入口与全局导航。
- `style.css`：响应式视觉与动画。
- `app.js`：页面、筛选、关系网、测试流程、保存和导出。
- `data.js`：11 位角色、引文、羁绊与互动统计。
- `tests.js`：测试注册和评分器。
- `audio.js` / `audio.css`：声音控制、偏好、语义音效和动态按键。
- `assets/audio/keikai-na-rhythm.mp3`：BGM 原文件。
- `vendor/cuelume/`：Cuelume 0.2.2 本地构建、MIT 许可证和来源说明。
- `serve.cjs`：可选的本地预览服务。
- `assets/avatars/`：用户提供的 11 张头像，按文件名与角色对应；原文件直接复制。结果卡使用同一图片的内嵌数据以支持离线导出。

原 DOCX、PDF 与羁绊 Markdown 保持独立。网页可以通过复制整个文件夹继续编辑或部署。
